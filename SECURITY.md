# SECURITY · meta-layer-kit

- **Сообщить об уязвимости:** заведи issue с меткой `security`, опиши условия воспроизведения, без публикации рабочего эксплойта.
- **Секреты (Устав I-5):** ключи живут только в Actions secrets или в локальных файлах вне git-слежки. Токен, побывавший в чате, скриншоте или истории, считается скомпрометированным — немедленная ротация, затем инцидент в реестр.
- **Кит не запрашивает ключей сам:** `bootstrap.sh` принимает ключ только скрытым вводом; сухой прогон работает без ключа вовсе.
- **Контур включён:** secret scanning + push protection ловят утечку прямо при пуше (см. настройки репозитория).
